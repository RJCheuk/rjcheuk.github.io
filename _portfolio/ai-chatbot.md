## Overview
Residency-RAG is an AI-powered assistant designed to support **internal medicine residents** by enabling fast, structured clinical knowledge retrieval.  
It reduces cognitive load and helps trainees access workflow-relevant information during real-world practice.

## My Role  
**Full-Stack Engineer & UX Study Designer (Oct 2025 – Present)**

- Designed the conversational interface and user experience  
- Implemented RAG pipeline with structured clinical knowledge bases  
- Developed backend (FastAPI) + dashboard for usage insights  
- Designed learning analytics:
  - Concept mastery mapping  
  - Question topic clustering  
  - Uncertainty indicators  
- Collaborated with physicians on evaluation design & workflow integration  
- Prepared usability study protocol grounded in cognitive load theory  

## Technical Contributions

- **Backend:** FastAPI, RAG pipeline, Chroma / LlamaIndex  
- **Analytics:** clustering, trajectory visualization, user diagnostic metrics
